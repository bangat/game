# 이슬숲 탐험대

미니게임지옥에 추가한 공용 온라인 곤충·공룡 수집·육성·턴제 전투 RPG입니다.

## 공개 실행

기존 앱 https://bangat.github.io/game/ 에서 대기실에서 **이슬숲 탐험대 → 참가**를 누릅니다. 모두 같은 공용 탐험 공간에 자동 합류하며, 캐릭터와 마지막 위치를 이어갑니다. 별도 앱 설치나 집 PC가 필요하지 않습니다.

- 화면: 기존 GitHub Pages의 `insect_expedition/`.
- 전투·채집 서버: 서울 리전 Cloud Run `insect-expedition`.
- 인증: 기존 Firebase `goodluck-7c14b`. 공용 탐험은 별도 방 생성·호스트·시작 버튼 없이 로그인 토큰으로 참가합니다.
- 곤충·육성 기록: 비공개 Cloud Storage `goodluck-7c14b-insect-private`의 계정별 JSON. 클라이언트 접근은 차단하고 전용 서버 계정만 저장합니다.
- 서버는 저장 완료 후 응답하며, 객체 세대 조건으로 오래된 서버의 덮어쓰기를 거부합니다. 최근 이전 버전 5개를 보존합니다.
- 운영 서버 환경: `GCLOUD_PROJECT`, `FIREBASE_DATABASE_URL`, `INSECT_PROFILE_BUCKET`. 인증은 런타임 서비스 계정의 ADC를 사용하며 인증키 파일은 배포하지 않습니다.

방 상태가 메모리에 있으므로 현재 서버 최대 인스턴스는 1개입니다. 접속이 없으면 0개로 축소합니다. 접속 중에는 서버 사용 비용이 발생합니다. 향후 여러 서버로 확장하려면 방 상태 공유를 먼저 구현해야 합니다. 서버 재시작 시 진행 중 전투는 이어지지 않지만 저장된 곤충·퀘스트·사료·골드는 유지됩니다. 재접속하면 마지막 지역과 저장 위치로 돌아오며, 구버전 맵의 위치는 최초 한 번 마을로 이관합니다. 60초 유예 안의 같은 방 재연결도 진행 위치를 유지합니다. 서로 다른 방은 별도의 세계입니다.

## 탐험 방법

1. 처음 한 번 캐릭터와 한글 1~6자 이름을 만듭니다. 이후에는 계정에 저장된 캐릭터로 바로 접속하며 캐릭터와 이름을 다시 정하지 않습니다. 키보드 WASD/방향키 또는 휴대폰 왼쪽 이동 스틱으로 걷습니다.
2. PC에서는 마우스 우클릭 드래그, 휴대폰에서는 화면 드래그로 시점을 회전하고 두 손가락/마우스 휠로 확대·축소합니다. 기본 거리 29, 범위 16~52이며 선택한 배율을 저장합니다.
3. 상단 의뢰를 눌러 현재 위치에서 의뢰를 수락하고 완료 보상을 받습니다.
4. 곤충에 접근하면 채집 버튼이 나타납니다. 이름과 Lv.를 머리 위에서 확인할 수 있습니다.
5. 의뢰마다 정해진 사료 보상을 지급하며, 완료 후 다음 순환 의뢰를 받을 수 있습니다.
6. 곤충 메뉴에서 먹이 주기·편성·상세 능력치·이름 변경을 이용합니다. 사료 1개는 경험치 84이며, 1레벨 곤충에게 3개를 주면 5레벨이 됩니다.
7. 진화 가능한 종은 Lv.5부터 진화합니다. 애벌레→나방, 굼벵이→풍뎅이, 수채→잠자리, 동굴사슴벌레→왕사슴벌레의 모습·공격·기술이 바뀝니다. 기본 곤충 9종은 Lv.8 또는 Lv.12에 각성 진화합니다. 성장 창에서 필요한 레벨과 최종 형태를 확인합니다.
8. 상단 현재 위치 또는 지도를 눌러 지역 이름·접속 인원을 확인하고 원하는 지역으로 바로 이동합니다. 마을을 거칠 필요가 없으며 같은 지역의 탐험가끼리 만납니다. 전투·채집 중에는 이동할 수 없고, 이동해도 탈것과 캐릭터 기록을 유지합니다.
9. 야생 곤충은 전투에서 승리하면 확률에 따라 자동 채집합니다. 성공하면 곤충 이름·보상을 중앙 알림창에서 확인합니다. 전투 후 팀은 자동 회복합니다. 쓰러진 곤충이 강제로 교체되면 다음 턴은 새 곤충이 선공하며 이후에는 속도 순서로 돌아갑니다.
10. 성장 → 조합에서 같은 종류 3마리와 골드를 사용해 더 강한 종으로 성장합니다. 기준 곤충의 레벨·경험치·팀 배치를 유지합니다. 팀 밖 재료 2마리와 비용을 확인한 뒤 확정하며, 성공 확률은 100%입니다.
11. 안전 마을을 제외한 8개 사냥터마다 보스가 1마리 있습니다. 공용 공간에서 선점 상태를 공유하며 처치하면 경험치 2배·골드 3배와 추가 사료를 얻고 5분 뒤 재출현합니다. 도주·패배 시에는 보스가 남습니다. 아무도 접속하지 않아 공간이 정리되거나 서버가 재시작하면 필드가 초기화됩니다.
12. 같은 방·같은 지역의 탐험가는 서로 볼 수 있습니다. 마을 밖 10m 이내에서 상대를 누르고 대전을 신청하면, 상대가 수락한 경우에만 3대3 친선 대전을 시작합니다.

## 로컬 개발

`npm ci` 후 `npm run start:firebase`로 기존 로컬 Firebase CLI 로그인을 이용할 수 있습니다. 포트 4194이며 로컬 기록은 `data/profiles.firebase.json`에 저장합니다. 이 개발 모드는 공개 서버와 별개입니다.

운영 데이터와 분리한 테스트는 `npm run emulators`와 `Start-Local.ps1`을 사용합니다. 테스트 규칙 `tests/emulator.rules.json`은 운영에 배포하지 않습니다.

## 검증

```powershell
npm run build:release
node --test tests/battle.cjs tests/server.cjs tests/progression.cjs tests/adventure.cjs
node tests/adventure-browser.cjs
```

Release 검사는 문법·메뉴 연결·자원 경로·UTF-8 무 BOM·해시를 확인합니다. 서버 테스트는 권한·중복 명령·채집·전투·재접속과 실제 의뢰 진행→보상→성장→진화→저장 복원을 검증합니다. 화면 시험은 데스크톱과 휴대폰 크기의 실제 Chromium에서 수행합니다.

아직 검증하지 않은 범위: 실제 휴대폰의 장시간 발열/성능, Safari, 대규모 동시 접속, 전투 중 서버 강제 종료 복구. 모든 기존 미니게임의 전체 플레이를 회귀 시험했다는 의미는 아닙니다.

## 사냥터 확장 · 2026.09.20.9

- 월드는 가로·세로 480m로 기존 면적의 4배입니다. 지역마다 종별 3개 서식 군락을 두며, 가까운 필드 생물만 렌더합니다.

- 공룡 6종을 포함한 총 27종을 수집합니다. 새싹랩터·늪독딜로·화강트리케라·수정안킬로·화염랩터·고대폭군렉스는 전용 3D 모델을 사용합니다. 울림 동굴의 보스는 Lv.36 고대폭군렉스입니다.
- 달리기 소모는 초당 16→4, 회복은 초당 9→14입니다. 가득 찬 상태에서 연속 약 25초 달릴 수 있습니다.
- 근접 공격은 돌진, 원거리 일반 공격은 작은 투사체, 원거리 기술은 준비 동작·큰 투사체·기술별 효과를 사용합니다. 동굴·바위터·온실 전투장은 바위·수정 지형으로 전환합니다.
- 자체 합성한 전투 음악이 반복 재생되고 결과에 따라 승리·패배 효과음이 나옵니다. 종료·연결 해제·앱이 가려질 때 배경음악을 멈춥니다. 전투 중에도 소리 버튼으로 음악과 효과음을 끌 수 있습니다.

### 2026.09.20.11 · 탐험 연구와 동굴 부화
- 사료 1개 / 10개 / 모두 사용. 최고 레벨까지 필요한 개수만 사용하고 저장 실패 시 원본과 사료를 보존합니다.

- 기존 보유 레벨은 유지합니다. 새 승리 포획은 최대 Lv.5, 무리 경험치 배율은 1.7배로 조정하고 Lv.11부터 필요 경험치를 점진적으로 늘렸습니다.
- 별빛 광산 / 달빛 알 동굴 / 고대 수호자의 터 추가. 지도와 탐험 연구에서 길 안내를 시작할 수 있습니다. 광맥은 1분, 알 둥지는 3분 뒤 재생됩니다.

- 알 보관 12개, 동시 부화 3개. 수정 3개로 시작하고 이동 80m·자원 채집마다 온기 +1, 전투 승리 +2. 전용 알은 종류별 12/16/24 온기가 필요하며 종료 후에도 저장됩니다. 수정과 알은 모두 판매에서 제외됩니다.

# 이슬숲 탐험대 월드 자원 출처

- `world.js`의 지형, 식생, 건축물, 곤충, 캐릭터와 전투 효과는 Babylon.js 기본 도형과 코드로 직접 제작했습니다.
- `assets/ground-moss.png`는 이 프로젝트를 위해 새로 생성한 독창적인 이끼·풀 지면 텍스처이며 외부 게임 자산을 사용하지 않았습니다.
- 외부 게임의 모델·캐릭터·음악·효과음을 가져오지 않았습니다. 곤충 모델과 날개·갑각 질감은 코드로 직접 제작했습니다.
- 렌더러는 프로젝트에 이미 포함된 Babylon.js 9.27.1 번들을 사용하며 해당 라이선스는 `sky_tower/vendor/BABYLON-LICENSE.md`에 있습니다.
- `original` 캐릭터 ID는 기존 저장값과의 호환을 위한 이름일 뿐, 기존 이미지나 권리 미확인 아바타 파일을 불러오지 않습니다.

## 이번 작업에서 생성한 이미지

- `assets/title-forest.png`: 이미지 생성 도구로 제작한 독창적인 숲 타이틀 일러스트입니다. 실제 게임 화면을 찍은 이미지가 아닙니다.
- `assets/ground-moss.png`: 이미지 생성 도구로 제작한 이끼·풀 지면 텍스처입니다. 실제 월드와 전투장 지면에 타일링합니다.
- 두 이미지 제작일: 2026-09-20. 참조 게임 이미지나 제3자 캐릭터를 입력하지 않았습니다. 특정 기존 게임의 스타일·맵·자원을 복제하도록 요청하지 않았습니다. AI 생성물의 독점 저작권 등록 가능성까지 보장하는 표시는 하지 않습니다.
- 타이틀 제작 요구: 곤충 눈높이의 독창적인 새벽 온대림, 이끼 뿌리·양치식물·개울·작은 자연 연구소, 오른쪽 전경의 장수풍뎅이와 나비, 섬세한 자연 재질과 따뜻한 빛, 왼쪽 UI 여백. 텍스트·상표·기존 캐릭터 없음.
- 지면 제작 요구: 수직 시점의 연속 반복 가능한 풀·이끼·클로버·작은 흙 틈, 차분한 올리브/에메랄드/세이지 색, 방향성 빛·그림자·원근·문자·테두리 없음.
- `assets/creatures/*.png`, `assets/characters/*.png`, `model-gallery.png`: 이 게임의 실제 Babylon.js 3D 모델을 Chromium으로 렌더한 이미지입니다. 2D 일러스트로 게임 모델을 대신하지 않습니다.

## 소리

- `audio.js`: 점프가 없는 본 게임의 타격·기술·포획·실패·결과 효과음을 Web Audio 오실레이터로 합성합니다. 녹음물이나 외부 음원을 사용하지 않았습니다.
- `assets/room-enter.wav`, `assets/room-leave.wav`: 이 로컬 작업에서 합성 제작한 짧은 입장·퇴장 음입니다. 기존 만료된 외부 음원 URL을 대체합니다.

## 런타임과 의존성

기존 Babylon.js 번들의 Apache-2.0 고지를 배포 패키지에 보존합니다. Express, ws, Firebase Admin, Playwright의 버전은 package-lock.json에 고정하며 해당 패키지의 라이선스 고지는 설치된 각 패키지에 포함됩니다. 새 캐릭터나 곤충에 기존 상용 게임 이름·로고·모델을 포함하지 않았습니다.

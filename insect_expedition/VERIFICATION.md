# 공개 배포 추가 검증 · 2026-09-20

이전 기록 아래의 '공개 배포 미수행'은 당시 로컬 검증 시점의 기록입니다. 이후 Cloud Run 서버와 비공개 영구 저장소를 구성했습니다.

- Release 문법/UTF-8/메뉴/자원 검사 통과.
- Node 테스트: 서버·전투·월드 9개 통과, 에뮬레이터 전용 1개 건너뜀. 별도 의뢰 진행·성장·진화·재시작 복원 테스트 통과.
- Chromium: 모바일/데스크톱 퀘스트·지도·육성 화면, 이미지 로딩, 겹침 수정 확인.
- 공개 Cloud Run HTTPS/WSS: 실제 Firebase 임시 계정으로 방 인증, 캐릭터 변경, 마을 귀환, 퀘스트 수락 후 비공개 저장소에 기록된 값을 별도 관리자 읽기로 확인.
- 테스트용 계정과 방은 검증 후 정리합니다. 실제 사용자 계정/방은 수정하지 않습니다.

검증 환경: Windows, Node v24.14.0, 시스템 Chrome/Playwright, 로컬 Firebase Auth 9099와 RTDB 9000. 운영 데이터에 테스트 방/계정을 만들지 않았습니다. 최종 브라우저 시험에서 처리되지 않은 자바스크립트 예외는 0개였습니다.

## 서버 테스트 범위

포획 성공/실패 난수 경계, 소유하지 않은 곤충 편성 거부, 타인의 전투 명령 거부, 동일 필드 선점, 잘못된 턴/행동 거부, 중복 명령·보상 처리 방지, 꽉 찬 보관함, 안전구역 도전 거부, 도전 거절·만료, 연결 해제 60초 유예와 판정·복귀, 동일 계정 다른 방 활동 제한, 재접속, 구버전 스키마·빈 팀·알 수 없는 종 복구를 자체 테스트 서버에서 확인했습니다.

필드전/PvP 전투 판정은 서버가 수행했습니다. 브라우저 전체 흐름은 일반 공격을 중심으로 완주했습니다. 고유 기술·진화·포획 확률 경계는 전투 단위 시험과 별도 실제 3D 렌더 시험에서 확인했습니다. 이 구분을 모든 기술 조합을 실제 다중 브라우저로 완주했다는 의미로 확대하지 않습니다.

## 수정 후 재검증한 문제

이동 스틱과 메뉴 겹침, 교체 창 숨김 실패, 버튼 대비, 전투 HUD 겹침, 방장 퇴장 시 좌석 잔존, 캐릭터 원격 모델 갱신, 일반 공격의 스킬 오판, 타격 효과 높이, 교체 모델·마지막 턴 이벤트, 저프레임 연출 시간, 전투장과 월드 공용 재질 해제를 수정했습니다.

## 검증하지 않은 범위

- 실제 Android/iPhone/Safari 기기 성능·발열·메모리와 장시간 조작.
- 다중 운영 서버, 대규모 동시접속, 운영 Firebase 전체 규칙과 기존 개별 게임의 전체 플레이 회귀.
- 서버 프로세스 중단 후 진행 중 전투를 그대로 복구하는 기능.
- 상용 수준 아트 품질 승인, 개인정보 운영 절차, 스토어 출시 및 설치 패키지.

현재 결과는 실제 플레이 가능한 로컬 통합 검증판입니다. 고해상도 수작업 곤충 모델·전문 리깅·대규모 환경 제작이 완료된 상용 RPG와 동일한 품질이라고 주장하지 않습니다. 운영 푸시·배포·규칙 변경은 수행하지 않았습니다.

## 보관과 재현

서버는 포트 4193에서 백그라운드 유지했습니다. `README.md`의 두 터미널 실행 방법과 일반/시크릿 창 순서로 재현할 수 있습니다. 데이터·로그·인증정보·node_modules는 배포 ZIP에서 제외합니다. `SHA256SUMS.json`이 배포 파일 무결성 목록입니다.

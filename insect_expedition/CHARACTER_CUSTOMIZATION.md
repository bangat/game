# 캐릭터 생성과 꾸미기

- 새 계정은 남자·여자 캐릭터와 한글 1~6자 이름을 처음 한 번 확정합니다. 서버 저장 완료 후 입장합니다.
- 기존 계정은 저장된 탐험가 이름·캐릭터 ID와 수집·주택·재화를 유지하고 최초 선택 화면을 건너뜁니다. 외형은 기존 캐릭터의 색을 참고한 새 공통 몸체로 표현합니다.
- 이후에는 게임의 `꾸미기`에서 헤어, 머리색, 표정, 눈 색, 피부색, 체형, 키(90~110%), 상의·하의·신발, 머리 장식, 소품, 의상 색을 변경합니다. 초기 남자·여자 선택과 이름은 바뀌지 않습니다.
- 모든 꾸미기 항목은 현재 무료입니다. 6개 추천 스타일을 빠르게 입어 보거나 직접 조합할 수 있습니다.
- 독립된 3D 미리보기에서 회전·얼굴 확대가 가능하고, 저장 전 변경과 취소는 실제 외형에 영향을 주지 않습니다. 저장 실패 시 선택한 모습과 이름 입력을 유지해 다시 시도할 수 있습니다.
- 계정 프로필에 외형을 저장하고 같은 방 플레이어에게 전달합니다. 브라우저 저장소를 지워도 서버 기록으로 복원합니다.
- 공통 어깨·골반·무릎 관절에 의상을 연결하여 걷기·벌목·채광·오토바이·리어카 동작을 공유합니다. 탑승 시 키에 따른 골반 높이와 스커트 길이를 보정합니다. 새 탈것 유형에는 별도의 좌석과 자세 조정이 필요합니다.
- 기존 수작업 캐릭터 ID는 호환용으로 유지합니다. 스키마 8에서 `characterCreated`와 `appearance`를 추가하며 기존 유효한 탐험가 이름을 최초 생성 완료의 근거로 사용합니다.

## 관련 검증

`npm run build:release`, `node --test tests/appearance.cjs`, `node --test --test-name-pattern=프로필 tests/server.cjs`, `node tests/appearance-browser.cjs`.

브라우저 검증은 실제 로컬 WebSocket 서버와 Chromium을 사용하고 Firebase 인증·방 조회만 시험용으로 대체합니다. 최초 생성·기존 계정 이관·닉네임과 캐릭터 변경 거부·저장 실패 원자성·외형 검증·꾸미기 취소·다른 플레이어 외형·탈것 2종·벌목·PC 및 휴대폰 가로/세로 화면·브라우저/서버 재시작 후 복원을 확인합니다. 휴대폰은 화면과 터치 에뮬레이션이며 실제 Android/iPhone 성능은 검증하지 않았습니다.

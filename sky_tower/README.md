# 구름끝 타워

미니게임지옥의 기존 계정과 방을 사용하는 1~6인 3D 타워 등반 게임입니다. 기존 게임과 캐릭터 자원을 유지하며 Babylon.js 엔진과 자체 타워 맵을 사용합니다.

## 참가 방법

1. 미니게임지옥 대기실에서 방 만들기를 누르고 **구름끝 타워**를 선택합니다.
2. 친구는 기존 방 목록 또는 게임방의 초대 링크로 참가합니다. 별도의 타워 방코드는 없습니다.
3. 방장이 게임을 시작하면 같은 타워로 이동합니다. 빈자리가 있으면 진행 중에도 참가할 수 있습니다.
4. 혼자하기 메뉴에서는 네트워크 방 없이 연습할 수 있습니다.

모바일에서는 왼쪽 스틱으로 이동하고 오른쪽 점프 버튼을 누릅니다. 빈 화면을 밀면 시점이 돌아갑니다. PC에서는 WASD 또는 방향키, Space 점프, R 체크포인트 복귀를 사용합니다. 움직이는 발판, 사라지는 발판, 회전 장애물을 지나 체크포인트를 순서대로 밟고 정상에 도착하세요.

## 로컬 실행과 검증

이 폴더에서 실행합니다. Node.js와 Chrome이 필요하며, 멀티플레이 테스트에는 Java와 Firebase 에뮬레이터도 필요합니다.

```powershell
npm ci
npm start
```

연습 주소: `http://localhost:4173/sky_tower/?mode=solo`

별도 터미널에서 에뮬레이터를 실행한 뒤 테스트합니다.

```powershell
npm run emulators
```

```powershell
npm run build
npm test
```

`build`는 정적 웹 게임의 Release 검증입니다. 문법, 자원, 메뉴 연결, UTF-8 저장 상태를 검사하고 `release-manifest.json`에 자원 해시를 기록합니다. APK나 iOS 설치 패키지를 만드는 명령은 아닙니다.

## 멀티플레이 데이터와 운영 반영

기존 Firebase 인증과 `rooms/{roomId}`의 참가자 정보를 사용합니다. 타워 진행 상태는 `skyTowerSessions/{roomId}`에 저장하여 기존 게임 상태와 분리합니다. 새로고침·연결 복구 시 체크포인트와 완주 기록을 복구합니다.

`database.rules.json`은 **타워 경로에 추가할 규칙 조각**입니다. 운영 데이터베이스 전체 규칙으로 덮어쓰면 안 됩니다. 기존 운영 규칙을 보존한 상태에서 `rules.skyTowerSessions`만 병합하고 상위 경로의 허용 규칙도 확인해야 합니다. `firebase.emulator.json`과 `tests/emulator.rules.json`은 로컬 검증 전용입니다.

위치와 점프는 각 기기에서 계산하고 Firebase로 공유합니다. 서버가 모든 이동을 판정하는 부정행위 방지 시스템은 포함하지 않습니다. Android·iPhone 브라우저에서 사용하는 웹 게임이며, 실제 기기의 성능과 설치형 앱 패키징은 별도 검증 대상입니다.
